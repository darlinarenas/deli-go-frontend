MÓDULO PENDIENTE — INVITAR COMIDA / UBICACIÓN DINÁMICA

Objetivo:
Implementar función “Invitar comida” en DELI GO/Bhuz para resolver entregas a terceros y mejorar direcciones en Venezuela.

Flujo esperado:
1. Usuario realiza pedido.
2. En checkout puede elegir:
   - “Es para mí”
   - “Invitar comida a alguien”
3. Si elige invitar:
   - escribe nombre,
   - teléfono opcional,
   - mensaje opcional.
4. Sistema genera link temporal único.
5. Link puede compartirse por:
   - WhatsApp,
   - SMS,
   - copiar enlace.
6. Persona receptora abre el link.
7. Comparte su ubicación GPS.
8. Puede agregar referencia escrita.
9. Sistema guarda:
   - GPS,
   - referencia,
   - nombre receptor,
   - teléfono.
10. Pedido continúa flujo normal ya existente:
   pendiente → aceptado → preparando → listo → en camino → entregado.

IMPORTANTE:
- El receptor NO necesita cuenta.
- GPS debe ser obligatorio.
- Dirección escrita + referencia + GPS.
- Mantener máximo 5 direcciones propias por usuario.
- Permitir guardar direcciones frecuentes.
- Crear módulo “Personas frecuentes” para futuras invitaciones.
- Preguntar:
  “¿Usar dirección guardada o pedir ubicación actual?”
- Historial del pedido debe conservar ubicación usada.

IDEA CLAVE:
La innovación NO es solo regalar comida.
La innovación es:
“Te envío comida y tú compartes tu ubicación exacta para recibirla.”

Prioridad:
Implementar después de:
1. Notificaciones globales.
2. Sonidos globales.
3. Pop-up de compra en index.
4. Campanita global conectada a mis pedidos.
